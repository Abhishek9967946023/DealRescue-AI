# 60-second demo script

**0–10 sec**
“Imagine you are a sales rep on the fifth call with a $185K enterprise customer. They say we are too expensive and Competitor X is cheaper.”

**10–20 sec**
“Normal AI can give generic sales advice. DealRescue first checks what happened in previous deals.”

Click **Load 12 realistic experiences** and **Generate Next Best Action**.

**20–35 sec**
“Here it remembers that discount-first negotiation stalled, while ROI-led conversations progressed.”

Show Memory Evidence.

**35–45 sec**
“Then Hindsight Reflect turns those experiences into a decision: don't discount first; quantify value and trade concessions for commitment.”

Show Next Best Action and Before → After.

**45–55 sec**
“Now the rep records what actually happened. Even a failed deal becomes useful experience.”

Use Deal Autopsy.

**55–60 sec**
“So DealRescue doesn't just remember sales conversations. It learns which interventions actually rescue the next deal.”


## Signature Learning Experiment

The strongest demo moment is not the first recommendation. It is the visible change after a new outcome becomes memory.

1. Start with the Northstar pricing objection.
2. Show the cold-start recommendation.
3. Click **Run learning experiment**.
4. The system records a failed discount-first outcome through the same retain path used by Deal Autopsy.
5. The same situation is evaluated again against accumulated experience.
6. Show the two recommendation cards side by side.
7. Point to the line explaining whether the recommendation changed because the new outcome entered the experience loop.

Judge message:

> The agent did not simply retrieve the past. The past changed its next decision.
